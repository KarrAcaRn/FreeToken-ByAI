begin

    Result := cv / 12.92
  else
    Result := Power((cv + 0.055) / 1.045, 2.4);
end;

    Result := Arctan(y / x) * 180.0 / Pi
  else if (x < 0.0) and (y >= 0.0) then
    Result := (Arctan(y / x) + Pi) * 180.0 / Pi

    Result := 90.0
  else if (x = 0.0) and (y < 0.0) then
    Result := 270.0
  else

end;

1. **`Duplicate identifier "C"`**: Die lokale Variable in `sRGBToLinear` wurde von `c` in `cv` umbenannt, damit kein Konflikt mehr mit dem Parameter `C` besteht (Free Pascal ist im Delphi-Modus nicht automatisch case-sensitiv).
2. **`Identifier not found "Atan2"`**: Free Pascal bietet in der `Math`-Unit keine `atan2`-Funktion. Stattdessen wurde eine eigene `atan2Deg(y, x)` eingeführt, die `Arctan` (aus der `System`-Unit) mit der korrekten Quadrant-Logik kombiniert und direkt Grad im Bereich [0, 360) liefert.
